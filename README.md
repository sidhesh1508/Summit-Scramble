# 🏔️ Summit Scramble

**Summit Scramble** is a 3D game developed using Unity and C#. This project focuses on player movement, physics, and interactive gameplay mechanics.

## 🎮 About the Project

Summit Scramble is a game development project created as part of VGP236 coursework.

The project explores fundamental concepts of 3D game development, including character controllers, physics-based movement, and player input systems.

## ✨ Features

- **Player Movement:** Character movement controlled through player input.
- **Jumping Mechanics:** Player jumping using Unity's physics system.
- **Ground Detection:** Checks whether the player is standing on a surface.
- **Camera Controls:** Camera movement for navigating the 3D environment.
- **Physics Integration:** Uses Unity's Rigidbody and collision systems.
- **Input System:** Uses Unity's Input System for player controls.

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/sidhesh1508/Summit-Scramble.git
   ```

2. Open Unity Hub.
3. Select **Add Project from Disk**.
4. Select the cloned `Summit-Scramble` folder.
5. Open the project using a compatible Unity Editor version.
6. Open the main scene in the `Assets/Scenes` folder.
7. Press **Play** in Unity Editor.
